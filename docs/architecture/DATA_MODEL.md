# Data model (Flyway `V1__core_schema.sql`)
Identity: `users`. Sources: `data_sources`, `ingestion_runs`, `ingestion_errors`. Telemetry: `raw_events` (payload jsonb + sha256), `normalized_events` (unique `(source_id, fingerprint)`, GIN full-text, indexes on ts/host/user/ip/class/domain), `assets`, `coverage_expectations`. Detection: `detection_rules`, `rule_versions` (DRAFT/APPROVED/REJECTED/SUPERSEDED, fingerprint), `rule_test_runs`, `suppressions`. Work: `alerts` (unique dedupe_key), `alert_evidence`, `alert_history`, `incidents`, `incident_alerts`, `incident_evidence`, `incident_notes`, `incident_tasks`, `incident_activity`. Hunt/intel: `hunt_searches`, `hunt_notebooks`, `threat_indicators`. Response: `response_proposals`, `response_approvals`, `verification_results`. Other: `ai_analysis_runs`, `notifications`, `audit_events` (hash chain), `system_settings`, `report_exports`.
Not created (spec candidates deferred): sessions table (container sessions), roles tables (role column), `source_health_checks`, `ingestion_checkpoints` (no live connectors), `event_entities`, `asset_source_coverage` (computed), `response_simulations` (stored on proposal), `ai_evaluations` (computed on demand).
